# MNIST HVO2 OOD 项目上下文

## 总目标与当前阶段

构建简单HVO2网络，研究类别相关的振荡活动稀疏性及分布外检测。当前已在TAC思想的固定类别区域软约束网络上加入 **基于振荡时长、训练集类别均值与余弦相似度的OOD判决**，不引入SAE。

工作目录按用户指定为 `HVO2/ODD/`，仅保留 `Spare_NN_OOD.ipynb` 和本上下文文件。共享源码/数据分别复用 `../finite_oscillation_model.py` 与 `../data/MNIST/raw/`，不复制。支持从仓库根目录、HVO2或ODD启动。

## 已确认的数据与网络

- MNIST原始28×28灰度，无平移/背景噪声。合并官方60,000/10,000两分区后，所有参与数字先按最少类别下采样，再逐类90%候选/10%测试；候选中1/9独立ID校准，总训练∶校准∶测试约8∶1∶1。种子306879214。
- **当前未知标签1，ID标签为0、2–9。** 全局只修改`EXCLUDED_DIGITS`即可自动计算`TRAIN_DIGITS`补集、输出维数、内部标签映射、类别原型与图例；更换标签后须从头运行。最少类别数字5有6,313张，因此每个数字随机取6,313张。每个ID训练5,050、校准631、测试632；9个ID合计训练45,450、校准5,679、测试5,688。未知1从其独立测试分区取632张，混合测试共6,320张，各数字都632张，未知恰占10%。未知不参加训练、原型或阈值校准。内部索引0–8映射到0、2–9，最终未知仍记-1。
- 784个HVO2输入器件 → 441个HVO2隐藏器件 → 9维线性分类头，351,045个可训练参数。层间仍为稠密连接，不是稀疏权重/稀疏执行实现。
- 用户要求输入层灰度映射保持 **6.3–7.5 mA**，及参考文件的输入频率归一化，避免第一层用尽振荡潜力。
- 隐藏层可学习电流映射默认拓宽为 **6.3–10.0 mA**；上限可设为10.5、11等，没有10 mA硬上限。
- 固定器件频率/持续时间拟合保持不变，并与导入标量器件核对。高电流区使用原公式外推，尚未用额外硬件测量验证。
- 每张图独立从h=0开始。输入从全局时间0启动；隐藏层等待全部输入就绪。连续寿命按0.01 ms网格向上取整，再加0.0001 ms检测延迟；完整读出、不设截止门控。

## 完整脉冲判据与特征

用户明确希望长振荡集中到目标类别区域，高电流下不足一个脉冲时视为不响应。

- 用 `cycles = 原始频率 × 连续寿命_ms / 1000` 判断完整周期数。默认cycles≥1才有完整脉冲；必须在时间网格取整**之前**判断，防止取整制造脉冲。
- 6.3 mA约54.529 ms、1156.78周期；7.5 mA约3.322 ms、72.15周期；9.2 mA约0.03588 ms、0.805周期；10 mA约0.001304 ms、0.0297周期。10和11 mA均通过无完整脉冲检查。
- 亚周期响应仍有模型内部寿命/相位瞬态和提交时间，只是没有完整脉冲；不能描述为器件内部绝无变化。
- 隐藏分类特征为 `原始频率 / 隐藏上限参考频率 × 完整脉冲门控`。无完整脉冲时严格为0；有效长振荡仍有非零特征。没有继续减去低端频率，避免把6.3 mA长振荡也错误归零。
- 前向采用严格脉冲判据，门控反向使用log周期数上的sigmoid代理梯度，温度0.5。连续寿命可微，离散时间沿用直通梯度。
- 推理前向仅接收图像，不接收标签，不按真实类别屏蔽神经元。标签仅用于训练损失及离线统计/图形注释。

## 类别区域与软损失

- 默认21×21网格分成3×3个7×7块，按`TRAIN_DIGITS`顺序（当前0、2–9）从左上到右下对应，每类49个。
- 用户确认±10%针对**预分配区域大小**，严格整数45–53，不是每张图实际活动数的硬限制。`CLASS_REGION_SIZES`可分别设为不同大小，总数须为441。
- 非等分配置从超额区域向不足区域转让最近网格点，固定生成区域掩码；每个神经元恰好归属一类。已验证45/53/其余49有效，44/54会被拒绝。
- 固定掩码是监督编码，不是推理裁剪。实际响应允许软偏离，没有通过top-k或真实标签强行制造稀疏结果。
- AdamW，学习率1e-3，权重衰减1e-4，batch size32，默认5 epochs。
- 总损失：`分类交叉熵 + λ × 区域损失`。λ默认0.1，第1轮0.05，第2轮起0.1。
- 区内：不足40 ms时惩罚 `relu(log(40)-log(duration_ms))²`；区外：超过0.5周期时惩罚 `relu(log(cycles)-log(0.5))²`。
- 两项分别按区内/区外神经元数平均，再取平均，防止392个区外目标压倒49个区内目标。对数尺度同时处理几十ms与不足一周期的短响应。
- 这是借鉴TAC编码思想、直接约束真实器件响应的适配，**不是原论文直接复现**。不增加投影层，不冻结主网络；学习连接权重、偏置、电流映射偏移及尺度，器件拟合参数不训练。

## 输出与统计口径

保留4个指定章节、5个代码单元；第0部分集中所有依赖与可调参数，第1部分建立数据/模型/区域并展示预分配图。

- 每轮优化后，用同一组当轮结束权重重算训练/测试准确率、分类CE、区域损失及组合损失；优化期间平均batch损失单独记录。
- 每轮绘制固定测试集第1个样本的两层active/all—global time曲线。只计可产生完整脉冲的可观测活动区间 `[start, ready-detector)`，分母为全层神经元数。
- 每轮隐藏层热力图为与最终测试相同布局的3×3组合图，模式由第0部分的`HEATMAP_SAMPLE_OCCURRENCE`控制：正整数表示各标签第几次出现的固定样本，字符串`'mean'`表示各标签全部分布内测试样本的逐神经元平均响应。用户已将当前值设为 **'mean'**，本次保留。mean模式与最终测试共用统计和绘图函数；无完整脉冲响应按0参与平均。测试均值只用于可视化，绝不复用为OOD原型。
- 整数热力图模式按当前平衡后的ID测试顺序，为每个实际ID数字选第n次出现的位置，记录于`HEATMAP_TEST_SAMPLE_IDS`；mean模式使用全部同类ID测试样本。更换未知标签或数据划分后须重新计算索引，旧不平衡版本的固定索引不可直接沿用。选择不依赖预测正确与否，epoch之间样本保持一致。
- 每轮九类热力图复用轮末测试评估，不增加模型前向；整数模式缓存指定样本，mean模式只增加逐类聚合。两种模式均共享色标和区域轮廓，mean模式的`heatmap_history`记录各类样本数与均值矩阵。活动比例图继续使用测试集第1张样本；最终测试始终展示各类全部测试样本的平均响应，不受逐轮热力图模式影响。
- 最终分布内测试对全部测试样本按数字统计平均时长热力图，不筛选成功样本；不足完整脉冲的瞬态记为0。
- 另报告区内/区外平均连续寿命、发完整脉冲数量、区外发脉冲数量、寿命≥10 ms的长响应数、每样本目标区可观测总时长占比的平均值。时间占比不是神经元数量比例。
- 保留最后一轮权重，不按测试结果选轮次、不提前停止；测试标签不反向训练，最终测试样本不用于阈值选择；τ只来自独立ID校准分数和预设80% ID保留目标，数字0仅在最终评估时输入模型。
- `history`、`activity_history`、`heatmap_history`及`id_test_metrics`留在内存。默认不保存权重或独立图片；notebook中的输出是运行记录，重启kernel需从头执行以重建模型。

### 重复性与调试

- `BALANCE_SEED = RANDOM_SEED + 17`，下采样使用`BALANCE_SEED + 1009*digit`。
- 每数字候选/测试划分使用`RANDOM_SEED + 1009*digit`，校准划分使用`OOD_SPLIT_SEED + 1009*digit`。
- 因此切换未知标签时，同一数字的下采样集合与预留测试集合保持稳定，不因数字在ID/OOD列表中的位置而改变。
- 训练、校准、测试和未知测试的样本互不交叠。未知在阈值固定后才构造图像数据集并评分。
- `TRAIN_LIMIT`、`TEST_LIMIT`调试上限也向下取整为类别数的倍数，保持各ID等量；未知自动匹配实际单类ID测试量。不能把非整除上限解释成一定用满该数量。

## 当前余弦OOD协议（ID-only先验保留80%）

**继续遵守：阈值不能依赖未知输入。** 先前EER已移除；不预留未知校准分区，不使用未知或测试分数选τ。

- 无SAE。隐藏响应为441维可观测振荡时长`duration_ms × emitted`，无完整脉冲记0，与热力图一致；分类头使用原频率特征。
- 训练完成后，固定最终权重，仅以实际训练集按真实训练标签求原始时长均值，建立9个原型（每类5,050张）。先求均值，再在余弦计算时L2归一化。校准/测试/未知不参与原型计算。
- 分数`s=cos(h, mean_train[p])`，p是分类头预测类别，按`TRAIN_DIGITS`映射到真实数字；不根据测试真标签选原型，不取九类最大相似度。
- 阈值函数`choose_ood_threshold(id_calibration_scores)`只接收独立ID分数。`τ=np.quantile(id_scores,1-OOD_ID_RETENTION,method='lower')`，`OOD_ID_RETENTION=0.80`，即下侧20%经验分位数。
- `score < τ`判未知，`score >= τ`保留。校准ID保留率至少达到80%，同分时可更高；最终测试ID不保证恰好80%，未知召回率也没有80%保证。全零响应分数0，零原型报错。
- `OOD_COSINE_THRESHOLD=None`默认自动ID分位数；设置[0,1]数值可手动覆盖。未知仅在最终评估输入，数据集构造也在阈值固定之后。

其他重要参数保持：训练5 epochs、batch32、AdamW lr1e-3、weight decay1e-4、441隐藏、6.3–7.5mA输入、6.3–10mA隐藏、固定区域软约束；`HEATMAP_SAMPLE_OCCURRENCE='mean'`。手动改变数字配置后必须从头执行。

## 历史结果与最新决定

更早使用不均衡MNIST标签数，未知0、ID1–9；8∶1∶1分区下，ID-only 80%规则τ约0.784912、原始ID准确率95.23%、保留后准确度92.85%、未知召回率77.17%、AUROC0.871235。旧95%保留规则τ约0.311316、未知召回率41.23%。这些版本的未知占比不同，不可直接比较精确率。

曾短暂采用需要独立未知0的EER规则τ约0.802726，后因用户要求未知不能参与阈值计算而废弃。当前不能恢复EER或未知校准。

最新已完成类别等量下采样、每类等量分区、未知量与单一ID测试标签等量（10%）、未知从0换成1，以及参数自动派生与完整运行。后续更换单个未知数字仅改`EXCLUDED_DIGITS`并从头运行。保持ID-only 80%先验目标，不用未知或最终测试分数选择阈值。
